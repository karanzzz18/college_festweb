CLESTA 2026 — COLLEGE FEST WEBSITE
College: Quad AI School of Technology

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder named Clesta_2026_College_Fest_Website.
3. Double-click index.html. It will open in your browser.
4. Use the navigation bar to visit Home, Events, Schedule, Register and Contact.

PROJECT PAGES
- index.html: Home page, festival details, image and YouTube teaser iframe.
- events.html: Five events with date, time, venue, fee and descriptions.
- schedule.html: Festival timetable using colspan.
- register.html: Registration form with text/email/tel inputs, dropdown, radio buttons, checkboxes and textarea.
- contact.html: Organizing committee contact details, email link and college website link.
- brochure.html: Downloadable event brochure page.
- style.css: Shared styling for all pages.
- images/clesta-poster.svg: Local festival poster image.

IMPORTANT
This is a beginner-level HTML/CSS frontend project. The registration form is for demonstration only and does not save or send information. Event timings, fees, contact email and college website URL are sample details; confirm and replace them with official information if required.
